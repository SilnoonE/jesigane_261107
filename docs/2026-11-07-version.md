## 데이터 구성

| 테이블 | 책임 |
| --- | --- |
| members | 사이트 계정 ID, 표시 이름, 역할 |
| slots | 상담 예약 시간, 접수 여부 |
| entries | 상담 예약·대기의 접수 순서 |
| meetups | 친구 약속과 고정 예약금, 상태, 초대 코드 |
| guests | 약속 참여자, 예치 상태, 체크인 시각 |
| claims | 지각비 사용 제안과 승인 상태 |
| votes | 참여자별 찬성·반대 |
| expenses | 가상 모임비 사용 내역 |

마이그레이션 0000은 상담 서비스, 0001은 친구 약속 기능을 추가합니다. 이미 적용한 마이그레이션을 수정하거나 재실행하지 않습니다.

## 개발 환경

- Node.js >=22.13.0, npm과 package-lock.json
- React·TypeScript·Vinext
- Cloudflare Workers 및 D1
- Sites의 ChatGPT 로그인과 비공개 배포
- 별도 실결제 API 키 불필요: 현재 모의 결제만 구현

설치·마이그레이션·실행 명령은 루트 README.md에 있습니다.

## 검증 범위

- 직전 기능 구현 단계: scripts/test-meetups.mjs, scripts/test-booking.mjs 통과
- 브라우저: 약속 생성, 모의 예치, 샘플 투표 승인, 가상 지출 기록, 모바일 배치 확인
- 이번 브랜드·문서 변경: TypeScript 검사와 배포 빌드 재실행
- 실결제·실제 송금·외부 알림은 구현·검증 범위에 포함하지 않음

## 알려진 제한

- 현재 호스팅은 비공개입니다. 친구의 접속 권한은 초대 코드와 별도로 설정합니다.
- 체크인은 자기 신고이며 GPS 인증을 하지 않습니다.
- 투표 미응답이 있으면 정산을 보류하며 자동 동의나 강제 종료 기능이 없습니다.
- 모임비는 가상 장부입니다. 금액 지급·송금·출금은 발생하지 않습니다.
- 관리자 역할은 최초 비공개 접속자를 기준으로 부여하며 역할 관리 화면은 없습니다.
- API는 학습용 규모의 목록을 한 번에 조회합니다. 페이지네이션·감사 로그·알림은 다음 단계입니다.
