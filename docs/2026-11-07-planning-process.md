## 3. 제품 정의

**제시간에**는 친구들과 만나는 시간에 작은 약속을 걸고, 지각비 사용을 함께 결정하는 모임 서비스입니다.

- 대상: 친구 모임, 한강 나들이, 남산 야경 약속 같은 소규모 만남
- 핵심 가치: 기다리는 친구의 시간을 존중하고, 예약금 사용은 참여자의 명시적 합의로 처리
- 현재 범위: 작동하는 학습용 MVP와 결제 시뮬레이션
- 현재 수익 모델: 미정, 결제 수수료·수익화 기능 미구현

## 5. 주요 사용자 흐름

```text
모임장: 약속 생성 → 초대 코드 공유
친구: 사이트 접근·로그인 → 코드 참여 → 모의 예약금 예치
모임장: 전원 예치 확인 → 약속 확정
참여자: 체크인
지각 발생: 사용 목적 제안 → 당사자 제외 전원 투표
  전원 찬성 → 가상 모임비 전환 → 사용 기록
  반대 존재 → 해당 예약금 모의 환불
  미응답 존재 → 보류 유지
모임장: 투표 종료 확인 → 나머지 예약금 모의 환불·정산
```

초대 코드는 사이트 접근 권한과 별개입니다. 현재 호스팅의 비공개 접근 범위를 유지하고 있어 친구의 실제 계정 접속에는 별도 공유 권한 설정이 필요합니다.

## 6. 설계 원칙

1. 금액, 소유권, 권한, 상태는 서버에서 다시 확인합니다.
2. 화면에서 버튼을 숨기는 것만으로 권한을 보장하지 않습니다.
3. 사용자의 기기 시각 대신 서버 시각과 DB 쓰기 순서를 사용합니다.
4. 미응답을 자동 동의로 바꾸지 않습니다.
5. 확정 후 참여자를 고정해 만장일치의 분모를 유지합니다.
6. 같은 예치·표·모임비 전환을 중복 적용하지 않습니다.
7. 실제 결제가 없는 상태를 화면 전반에 분명하게 표시합니다.
8. 체험 데이터와 계정의 저장 데이터를 분리합니다.

## 7. 기술 선택과 변경 이유

처음 동시성 설명은 PostgreSQL 행 잠금 예시로 시작했습니다.
실제 배포 환경이 Cloudflare Workers와 D1을 지원하므로 D1의 원자적 SQL·batch와 제약으로 구현했습니다. PostgreSQL의 SELECT FOR UPDATE를 그대로 사용하지 않습니다.
React·TypeScript로 화면을 만들고 Vinext의 API 경로로 서버 로직을 연결했습니다.
로그인은 Sites의 ChatGPT 인증을 사용하고 별도의 비밀번호 시스템은 만들지 않았습니다.

상담 예약은 한 시간대의 유효 신청 중 DB ID가 가장 작은 한 명을 예약자로 정의합니다. 취소하면 다음 유효 신청이 자동으로 예약자가 됩니다.
친구 약속 투표는 atomic batch로 표 기록·승인/반대 판정·예치 상태 변경을 함께 처리합니다.
사용 기록은 INSERT 조건에서 잔액을 확인해 동시 요청의 초과 사용을 막습니다.

## 9. 검증 기록

친구 약속 구현 단계에서 로컬 배포 빌드로 다음 통합 검증을 통과했습니다.

- 중복 참여·모의 예치 차단, 확정 후 참여자 고정
- 타인 약속방 열람 및 비모임장 작업 차단
- 정시 도착자를 대상으로 한 투표 차단
- 당사자 투표 차단, 제안자 자동 찬성 없음
- 미응답 보류, 만장일치 승인, 반대 시 모의 환불
- 중복 표와 표 변경 차단
- 잔액보다 많은 동시 사용 기록 차단
- 정산·취소·미확정 만료 약속 환불

기존 상담 예약은 20명 동시 신청 시 예약자 1명·대기자 19명, 중복 신청 차단, 취소 후 승격, 타인 취소 차단을 검증했습니다.
브라우저에서는 약속 생성·카카오 모의 예치·체험 투표·모임비 기록·데스크톱/모바일 배치를 확인했습니다.
이 브랜드·문서 변경에서는 TypeScript 검사와 배포 빌드를 다시 실행합니다. 실제 결제사 연동 테스트는 수행 대상이 아닙니다.

## v0.2.1 추가 기획·수정

사용 중 약속 생성에서 공통 오류가 표시된다는 제보를 받아 실제 입력 화면을 확인했습니다.
화면에 남아 있던 시각은 현재보다 과거였으며, 특히 '현재 분'을 선택하면 초 단위로 이미 지나기 때문에 미래 시간 조건을 만족하지 못할 수 있습니다.
미래 시간 제한은 유지하되 현재 한국 시각·최소 선택 시각·구체적 필드 오류를 표시하고, 처음 열 때 약 한 시간 뒤의 기본값을 제공합니다.

추가 요청에 따라 예약금 없이 약속을 만들 수 있도록 0원 옵션을 기본으로 추가했습니다.
0원 약속은 예치와 지각비를 사용하지 않으며, 2명 이상 참여하면 결제 없이 확정할 수 있습니다.
기존 금액을 건 약속의 만장일치와 모의 환불 규칙은 유지합니다.
